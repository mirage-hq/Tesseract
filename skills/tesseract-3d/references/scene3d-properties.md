# Scene3D property reference

Generated by `cargo scene3d-properties-regen` from the canonical typed registry.
Verify with `cargo scene3d-properties-check`. Scene3D is default-off and its wire format is not stable.

These are `propertyName` controls, not all structural JSON fields. A name is accepted only when
its descriptor applies to the concrete target and its current selected mode. Repeated names
represent distinct mode-specific rows; they do not make a control universal. Optional controls
retain their documented unset meaning until a permitted write materializes them.

Geometry, materials, modifiers, camera lens modes, emitters, environment sources, scene constraints,
model joint/clip operators, text records and array kinds use the same admission descriptors in
editing and sampled evaluation. Parent, target, topology and selector changes remain structural.

For a particular item, use the canonical property visitor and typed getter; `NotApplicable`,
`Unset` and an authored value are distinct. Coupled constraints also require final-record validation.
